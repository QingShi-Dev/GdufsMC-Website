云城像素社网站旨在为社区成员提供一站式信息服务平台。

# 重要功能介绍

### 1. 服务器状态查询

在官网首页显著位置，设置了服务器状态实时查询看板。该模块通过对 Minecraft Server List Ping 协议的模拟，直接与服务器进行握手和状态请求，无需启动游戏客户端，即可在网页端一目了然地掌握

### 2. 高清导览地图

为了帮助新老成员更加熟悉游戏世界，特别从游戏内导出了高清导览地图，该地图以俯瞰视角呈现三个维度的建成区域，支持：

- 拖拽平移与滚轮缩放
- 查看建筑与机器的基本信息
- 通过名称或产物搜索定位
- 浏览建筑高清图片
- 切换全屏模式

![website-map-page](/content/news/images/website-map-page.webp)

### 3. CMS更新的动态页面

现在动态页面的全部内容都基于 GitHub 与 Sveltia CMS 的网页端管理系统。无需构建后端数据库，在公开的 GitHub 仓库中，历史修改一目了然，通过 Sveltia CMS 可视化编辑，直接修改代码来发布与更新，内容更新后网站自动同步，减少人工维护的成本

### 4. 轮播图逐步教程

鉴于《如何加入服务器.pdf》这一文档在群公告中并不显著和pdf文档的阅读体验一般，我将文档内容重新排版并转化为网页端可翻页的轮播图组件，放置在"游玩指南"分区中。

该轮播图具有以下特点：

- 对链接进行特别优化，显示突出
- 底部配有页数，可随时了解当前进度
